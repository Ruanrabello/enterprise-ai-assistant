# Enterprise AI Assistant — Front-end

Interface web desenvolvida com React, TypeScript, Vite e Tailwind CSS.

Consulte o [README principal](../README.md) para conhecer a arquitetura, configurar as variáveis de ambiente e executar a aplicação completa.

## Comandos

```bash
npm install
npm run dev
npm run lint
npm run build
```

O servidor de desenvolvimento utiliza `http://localhost:5173` por padrão.
